# uTimer
> Work Timer influenced by uWidget's Minimalistic Look

A clean, smart, and borderless timer application built with WinUI 3

Helps Freelancers, Developers, Creators track their pure working hours without any complex setups or bloated interfaces.

Overall features are influenced by "Back to Work" Timer

---

* **Smart Time Tracking**: Configure up to 3 target programs. The timer automatically runs only when one of these applications is actively being used.
* **Unobtrusive Design**: Borderless, rounded-corner UI that stays always-on-top without cluttering your workspace.
* **Fully Customizable**: Adjust the window opacity, switch between Dark, Light themes, and change the font family to match your desktop setup.
* **Lock Mode**: Lock the window in place to prevent accidental dragging while you work.

## How to Use
- Reset Timer: Resets time back to zero
- Program 1/2/3: Assigns the target applications you wish to track. The timer will continuously run only when one of these assigned programs is actively in focus.
- Timeout(sec): Configures the idle timeout threshold. The timer will automatically pause if no user input (mouse or keyboard) is detected for the specified duration.

- Theme: Switches the application interface between Dark, Light, or System default modes.
- Opacity: Adjusts the transparency level of the timer's background.
- Font Family: Customizes the typeface used for the time display.
- Lock Position: Pins the window to its current location, preventing it from being dragged or moved accidentally.
