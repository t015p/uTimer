# uTimer
> Work Timer influenced by uWidget's Minimalistic Look

Built with C# and WPF (.NET)

Helps Freelancers, Developers, Creators track their pure working hours without any complex setups or bloated interfaces.

<img width="351" height="327" alt="image" src="https://github.com/user-attachments/assets/4bf728ed-1c9b-497e-8b6c-c8ffeb1ba0dc" />

Overall features are influenced by "Back to Work" Timer

---

## Features
- **Always on Top**: Keeps your timer visible always while working
- **Smart Pause/Resume**: Doesn't have to pause/resume the timer status every time you go AFK.

## Options
- Reset Timer: Resets current time to 0
- Program 1/2/3: Designate which program to count 
- Timeout(sec): If you set Timeout to 3, 3 seconds without any action will cause timer to stop

- Theme: Light/Dark/System Theme
- Opacity: Controls the Backdrop opacity
- Font Family: Changes typeface
- Lock Position: Checking this will cause the program not to move
